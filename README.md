# Sally AI Website

A responsive, static marketing site for Sally AI, the market research and trading education product from ImperialX. The page explains Sally's educational focus across crypto, stocks, and commodities, while avoiding investment-performance claims or personalized financial advice.

## Preview locally

Open `index.html` directly in a browser. The site has no build step, framework, package manager, or third-party runtime dependency.

## Deploy on GitHub Pages

This repository includes a GitHub Actions workflow in `.github/workflows/pages.yml`. After Pages is enabled for the repository with **Build and deployment → Source → GitHub Actions**, pushes to `main` publish the site automatically. The workflow can also be started manually from the Actions tab.

## Site contents

- `index.html` — complete responsive landing page, styling, inline SVG illustrations, accessible FAQ and mobile navigation.
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow.

## Product and safety notes

All sample chart art is labeled illustrative, not live data. The site describes market education and research—not guaranteed outcomes or recommendations to buy or sell. The primary product link points to [imperialx.io](https://imperialx.io/).
